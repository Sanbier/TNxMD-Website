# TNXMD — Elite Gaming Hub & Direct Platform

Official Website: [https://tnxmd.io.vn](https://tnxmd.io.vn)

A premium dark gaming catalog built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. Designed mobile-first with high-intensity neon purple and electric blue aesthetics, verified game configuration profiles, and direct multi-channel communication (Discord, Telegram, Zalo, Facebook).

---

## Visual & Technical Identity

- **Theme**: Deep Black background (`#07070a`), glowing neon purple (`#a855f7`) and electric cyan (`#00f0ff`) accents.
- **Mobile-First Layout**: Fluid responsive design optimized for mobile screens, tablets, and ultra-wide desktop displays.
- **Catalog Page**:
  - TNXMD brand header with mobile navigation drawer.
  - Large gaming hero section with real-time status telemetry.
  - Live search bar and category / platform filter tabs.
  - Vertical game list with high-resolution left-aligned covers and rich game metadata.
  - Animated `HOT` badges for featured titles.
- **Game Detail Pages (`/game/[slug]`)**:
  - Full-width hero banner with dynamic backdrop overlays.
  - Interactive multi-screenshot gallery.
  - Engine & performance highlights.
  - Detailed system hardware requirements.
  - Prominent gradient contact action button.
- **Direct Contact Architecture**:
  - Direct individual contact URLs per title.
  - Multi-channel support modal: **Telegram**, **Discord**, **Zalo**, and **Facebook**.
  - Strictly no shopping carts, paywalls, or accounts.

---

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Vercel / Cloudflare Pages / Node.js Server

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/tnxmd/tnxmd-website.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
